# Руководство по настройке IAM
Целью данного руководства является описание ключевых действий по управлению пользователями, ролями и привилегиями на платформе The Platform.

## Шаг 1 - Создание клиента 

Клиент (Client) в терминологии IAM представляет собой "ресурсный сервер", в рамках которого реализуются политики управления доступом к отдельным функциям и ресурсам платформы.
