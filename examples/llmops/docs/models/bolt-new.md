# Модель Bolt.new
## Описание сервиса
Bolt.new представляет собой инновационное решение для разработки, которое позволяет интегрировать современные AI модели с веб-средой разработки, функционирующей на базе WebContainers от StackBlitz.

## Правила подключения
Для тестирования Bolt.new в контуре МТС мы использовали форк репозитория, который позволяет интегрировать различные модели AI, включая GPT, Antropic, Google Gemini и локальные модели Ollama. Это позволило нам развернуть репозиторий внутри корпоративной сети и использовать модели LLMOps.

- Репозиторий с добавленным доступом к моделям: GitLab MTS
- Доступ в контуре: Bolt RND AI MTS

## Примеры промптов

```
Создайте простую игру "Змейка" в браузере, которая будет адаптирована для использования на смартфоне.
Интерфейс должен быть минималистичным, с интуитивно понятным управлением с помощью экранных кнопок или свайпов.
Учтите, что игра должна быть легкой и отзывчивой, чтобы обеспечить плавный игровой процесс на мобильных устройствах.
Пожалуйста, добавьте счетчик очков и возможность начать игру заново без перезагрузки страницы.
```
